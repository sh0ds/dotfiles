# Keys

Every desktop shortcut. `Super + F1` shows this table as a searchable list, so keep it in sync with `.config/hypr/hyprland.lua` and `rice.lua`.

| Key | Action |
| --- | --- |
| `Super + Return` | Terminal |
| `Super + Space` | App search |
| `Super + B` | Firefox |
| `Super + E` | Files (Thunar) |
| `Super + O` | Notes (Obsidian) |
| `Super + I` | Chat |
| `Super + U` | Music |
| `Super + S` | SoundCloud |
| `Super + N` | Inbox and quiet mode |
| `Super + Shift + Escape` | Power menu |
| `Super + Escape` | Lock |
| `Super + 1…0` | Workspace |
| `Super + Shift + 1…0` | Move window to workspace |
| `Super + arrows / h j k l` | Focus window |
| `Super + Shift + arrows / h j k l` | Move window |
| `Super + R` | Reading layout on / off (doc in the middle, the rest on the sides) |
| `Super + V` | Float and centre / tile again |
| `Super + X` | Centre a floating window |
| `Super + F` | Fullscreen |
| `Super + M` | Maximise |
| `Super + T` | Flip the split |
| `Super + G` | Group / ungroup windows |
| `Super + Tab` | Next window in the group |
| `Super + Q` | Close window |
| `Super + Shift + B` | Hide / show the rail |
| `Super + D` | Docs search |
| `Super + F1` | This list |
| `Super + C` | Calculator |
| `Super + Shift + V` | Clipboard history |
| `Super + period` | Emoji picker |
| `Super + Shift + C` | Colour picker |
| `Super + Shift + T` | Copy text from a screen region (OCR) |
| `Super + Shift + N` | Night light on / off |
| `Super + Shift + P` | Proton Pass |
| `Super + Shift + U` | Unmount USB drives |
| `Super + Shift + R` | Start / stop a region recording |
| `Print` | Region screenshot to clipboard |
| `Ctrl + Print` | Region screenshot to draw on |
| `Alt + Print` | Captioned devlog screenshot |
| `Alt + Tab` | Window switcher |
| `Ctrl + Shift + Escape` | System monitor |
| `Super + Shift + M` | DJ VM |

# Keys

Every desktop shortcut, plus the media keys (volume, play, next, previous), which work on the lock screen too. `Super + F1` shows this table as a searchable list, so keep it in sync with `.config/hypr/hyprland.lua` and `rice.lua`.

| Key | Action |
| --- | --- |
| `Super + Return` | Terminal |
| `Super + Space` | Launcher: apps, or `=` maths, `>` commands, `/` windows, `:` emoji |
| `Super + W` | Overview of every workspace (click to focus, drag to move, middle-click to close) |
| `Super + B` | Firefox |
| `Super + E` | Files (Thunar) |
| `Super + O` | Notes (Obsidian) |
| `Super + I` | Chat |
| `Super + U` | Music |
| `Super + S` | SoundCloud |
| `Super + N` | Inbox and quiet mode |
| `Super + Shift + Escape` | Power menu |
| `Super + Escape` | Lock |
| `Super + 1…0` | Workspace |
| `Super + Shift + 1…0` | Move window to workspace |
| `Super + arrows / h j k l` | Focus window |
| `Super + Shift + arrows / h j k l` | Move window |
| `Super + Ctrl + arrows / h j k l` | Resize window |
| `Super + V` | Float and centre / tile again |
| `Super + X` | Centre a floating window |
| `Super + F` | Fullscreen |
| `Super + M` | Maximise |
| `Super + T` | Flip the split |
| `Super + P` | Pseudotile |
| `Super + G` | Group / ungroup windows |
| `Super + Tab` | Next window in the group |
| `Super + Q` | Close window |
| `Super + Shift + B` | Hide / show the rail |
| `Super + D` | Docs search |
| `Super + F1` | This list |
| `Super + C` | Launcher in maths mode (`=`) |
| `Super + Shift + V` | Clipboard history |
| `Super + period` | Launcher in emoji mode (`:`) |
| `Super + Shift + C` | Colour picker |
| `Super + Shift + T` | Copy text from a screen region (OCR) |
| `Super + Shift + N` | Night light on / off |
| `Super + Shift + P` | Proton Pass |
| `Super + Shift + U` | Unmount USB drives |
| `Super + Shift + R` | Start / stop a region recording |
| `Print` | Region screenshot to clipboard |
| `Ctrl + Print` | Region screenshot to draw on |
| `Alt + Print` | Captioned devlog screenshot |
| `Shift + Print` | Whole screen to ~/Pictures |
| `Super + Shift + S` | Region screenshot to clipboard (same as `Print`) |
| `Alt + Tab` | Launcher in window mode (`/`), last window preselected |
| `Ctrl + Shift + Escape` | System monitor |
| `Super + Shift + M` | DJ VM |

## Mouse

With `Super` held, and on the rail itself, where hovering anything also shows a short hint.

| Mouse | Action |
| --- | --- |
| `Super + wheel` | Previous / next workspace |
| `Super + left drag` | Move a window |
| `Super + right drag` | Resize a window |
| `Wheel on the workspaces` | Step through workspaces |
| `Click the clock` | Today (month, graphs, disks, Pi, now playing) |
| `Click a notification in the island` | Open it (or the inbox) |
| `Right-click a notification in the island` | Dismiss it |
| `Drag in the island while it shows the volume` | Set the volume |
| `Click the song in the island` | Media card |
| `Click now playing` | Media card (cover, seek, shuffle, loop) |
| `Right-click now playing` | Play / pause |
| `Wheel on now playing` | Next / previous track |
| `Click the network icon` | Control centre |
| `Right-click the network icon` | Network settings (nmtui) |
| `Wheel on vol` | Volume up / down |
| `Right-click vol` | Mute / unmute |
| `Click vol` | Control centre (outputs, mic, app volumes, Wi-Fi, toggles) |
